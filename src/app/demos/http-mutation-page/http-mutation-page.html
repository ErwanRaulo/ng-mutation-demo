httpMutation() is the mutation counterpart of httpResource(): request returns a request description ({{ '{' }} method, url, body {{ '}' }}) and the library sends it through HttpClient itself. That's why it can also expose statusCode, headers and progress. A fake HttpInterceptorFn (fake-http-backend.ts) stands in for the server, with an artificial 2 s delay.
