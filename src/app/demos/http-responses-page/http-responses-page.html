Three ways httpMutation() reads a response body: parse to validate or transform it, httpMutation.blob() / .text() for non-JSON bodies, and downloadProgress while it arrives. A fake HttpInterceptorFn (fake-http-backend.ts) stands in for the server, with artificial delays. Details in the library's recipes.

Validating the response with parse

"Create user (outdated response)" hits an endpoint that answers 201 with an old body shape ({{ '{' }} userId, fullName {{ '}' }}), so parse throws.

createUser: state

status
{{ createUser.status() }}
statusCode
{{ createUser.statusCode() ?? '—' }}
value
@if (createUser.hasValue()) { {{ createUser.value().name }} (#{{ createUser.value().id }}) } @else { — }
error
{{ createUser.error()?.message }}

With the outdated response, status is error while statusCode is still 201: the server has already applied the write. Treat it as a contract mismatch, not a failed write — retrying would create the user twice.

A file in the response: httpMutation.blob() + downloadProgress

@if (exportUsers.downloadProgress(); as p) {
{{ p.total ? ((p.loaded / p.total) * 100 | number: '1.0-0') + '%' : p.loaded + ' bytes' }}
}
status
{{ exportUsers.status() }}
value
@if (exportUsers.hasValue()) { Blob, {{ exportUsers.value().size }} bytes, type {{ exportUsers.value().type }} } @else { — }
error
{{ exportUsers.error()?.message }}

The request description sets reportProgress: true; the fake backend then emits DownloadProgress events (artificial 400 ms each) before the file. The request itself has no body: the file comes back in the response, so it's a download. uploadProgress tracks the request body instead (see the httpMutation() page) and stays undefined here.

Plain text in the response: httpMutation.text()

{{ purgeInactive.status() }}

@if (purgeInactive.hasValue()) { {{ purgeInactive.value() }} user(s) purged } @else { — }
error
{{ purgeInactive.error()?.message }}

The server answers with the plain-text body "2" (artificial 2 s delay). Since TOutput is number, not string, the typings make parse required: parse: (raw) => Number(raw). httpMutation.arrayBuffer() works the same way with an ArrayBuffer.
