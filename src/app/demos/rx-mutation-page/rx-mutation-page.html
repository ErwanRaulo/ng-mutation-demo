rxMutation() is the mutation counterpart of rxResource(): its mutationFn returns any Observable, typically an existing service method such as this.http.post(). The first emitted value resolves the call; reset() or destroying the component unsubscribes. Unlike httpMutation(), it doesn't see the HTTP events, so there is no progress, statusCode or headers. The fake backend adds an artificial 2 s delay.
